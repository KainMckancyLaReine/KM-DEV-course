Think

Prompt

Learn how to communicate with AI. Specific over clever: goal, constraints, structure, and the vocabulary that gets you a usable answer.

03

Build

Turn instructions into working code. Files, structure, and how a page actually reaches the browser.

04

Understand

Read what was generated. HTML structure, CSS decisions, and the difference between code that works and code you can change.

05

Break

Test everything. Small screens, slow connections, keyboard only, empty states — the places where generated code usually gives up.

06

Fix

Debug with AI. Describe the failure precisely, read the proposed fix, and verify it instead of trusting it.

07

Polish

Make it feel professional. Spacing, type scale, motion timing, focus states — the details that separate a demo from a product.

08

Ship

Put it online. Hosting, domains, and what to check the hour after it goes live.

05 / 08Compare

Don't blindly generate.

The same model, two prompts. The difference is not the tool — it is how much of the thinking you did before you asked.

BadGeneric
Make me a website.
Welcome to My Website Learn More

No audience, no structure, no constraints. The model fills the gaps with the average of everything it has seen.

GoodDirected
Build a responsive editorial portfolio for a two-person studio. 12-column grid, oversized Space Grotesk headlines, asymmetric project rows, one accent colour, generous whitespace, a single call to action. No stock imagery.
Halden
Brands that hold up in daylight.

Every constraint removes a wrong answer. That is all a good prompt does.

07 / 08Lesson

What should you ask AI?

C. Because it removes decisions.

A and B leave the model to invent the audience, the structure and the visual language. C names them, so the first result is close enough to be worth editing — which is where the real work starts.
